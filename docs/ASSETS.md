# Proveniência dos modelos

Fonte local autorizada pelo usuário: `refract/last-light/assets/kenney_space_kit/`.

Pacote original: Kenney Space Kit 2.0, https://kenney.nl/assets/space-kit. Licença CC0 incluída, com uso pessoal, educacional e comercial permitido. Os arquivos OBJ/MTL foram copiados sem alteração; os caches de importação do Godot foram recriados neste projeto.

O jogo usa astronautA, craterLarge, rock_largeA, rover, satelliteDish_detailed e machine_generator. O modelo hangar_roundGlass está preservado na seleção reutilizada, mas não é instanciado. Nenhum arquivo do Last Light foi modificado.

O arquivo `asset-hashes.json` registra SHA-256 dos arquivos copiados para verificar integridade. A licença e a cópia conferidas não substituem os testes de importação e renderização.
